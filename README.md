# \# Emotion Detector

# 

# This project is an Emotion Detection application using IBM Watson NLP.

# 

# \## Features

# 

# \- Detects anger

# \- Detects disgust

# \- Detects fear

# \- Detects joy

# \- Detects sadness

# \- Identifies the dominant emotion

# \- Provides a Flask web interface

# \- Handles invalid or empty input
